# 과거 주가 등록·재생 계약

실제 가격은 브라우저가 업로드하지 않는다. 운영자가 로컬 스크립트로 CSV 또는 토스 일봉을 가져와 검증한 뒤 서버 가격 목록에 등록한다. 기존 가상 가격은 계속 사용할 수 있다. 실제 API 인증정보가 없는 상태에서 외부 호출 성공이나 실제 데이터 확보를 주장하지 않는다.

## 입력과 표본화

- 국내 원화 종목, 6자리 영문·숫자 코드, 원 단위 양의 정수 종가와 0 이상 거래량.
- CSV 열은 `date,close,volume`, 날짜는 YYYY-MM-DD다. 토스 조회는 고정 호스트의 `GET /api/v1/candles`, `interval=1d`, `adjusted=false`만 사용한다. 계좌·주문 API는 호출하지 않는다.
- 월 0을 포함해 2~121개의 이미 끝난 달을 지정한다. 월 0은 유효 가격이 필요하다. 같은 날짜의 값이 다르면 거부한다.
- 월별로 **수집된 일봉 중 마지막 날짜**의 종가를 사용한다. 거래소 달력과 대조한 완전한 월말 자료라고 보장하지 않는다. 기록된 관측일은 보존한다.
- 중간 월의 가격이 없으면 null·거래 불가로 보존한다. 거래량 0은 체결을 막는다. 누락 가격을 미래 데이터로 채우지 않는다. 평가는 기존 엔진 규칙에 따라 이전 유효 가격을 쓸 수 있다.
- 수정주가·분할·배당은 처리하지 않는다. 실제 시연은 해당 기업 이벤트가 없는 검증 기간으로 한정한다. 비용은 0의 실험 가정이며 실제 금융 비용이 아니다.

## 출처와 등록

가격 묶음은 provider, sourceUrl(인증·query 없는 HTTPS), collectedAt, historicalStartMonth/EndMonth, adjustment, sampling, corporateActions, usageScope와 원본 해시를 포함한다. 해시는 출처·가격·이용 범위를 모두 포함하며 기존 ID 파일을 덮어쓰지 않는다.

기본 usageScope=private는 수집 파일만 저장하며 API 목록·직접 조회에서는 제외한다. 해당 프로젝트에서 표시할 수 있는 데이터만 운영자가 project로 등록한다. 토스 사용권이 자동으로 제3자 제공 권한을 뜻하지 않는다. 수집 파일과 인증정보는 Git에 추가하지 않는다. 서버의 MARKET_SERIES_DIR에서 승인된 project 가격 묶음을 읽는다. HTTP 등록/수집 엔드포인트는 제공하지 않는다.

투자 시작 시 원본을 DB에 고정하는 기존 정책을 유지한다. 이후 파일 교체/삭제에도 이전 투자 계획과 Run은 동일 원본으로 재현한다. 공개 source 메타데이터에는 전체 가격을 넣지 않는다. `/paper-plans/{id}/market`의 가격은 현재 진행 월까지만 노출하고 observedOn을 제공한다.

## 화면

가상/실제 과거 주가를 명확히 구분해 가격 묶음을 선택한다. 재무 조건의 경과 월 0은 선택한 과거 주가의 시작 월에 대응한다. 재무 모델의 기존 시작 월을 바꾸지 않으며, 가격·체결 기록의 날짜는 과거 주가 기준 월로 표시한다. 미래 예측과 실시간 거래로 표현하지 않는다.
