# 단일 종목 모의투자 계산 계약 v1

범위: 외부 API·DB·월별 진행과 분리한 순수 계산 함수. 테스트 가격만 사용하며 실제 주문을 전송하지 않는다. 기존 현금·저축 엔진과 서버 Run v1에는 아직 연결하지 않는다.

## 함수

- `createAccount({symbol, cash})`: 현금에서 시작하는 단일 종목 계좌. 초기 보유 주식은 0주다.
- `executeOrder(account, order, quote, costs?) -> {account, execution}`: 새 계좌 상태와 체결/거부 기록을 반환한다. 전달된 객체를 변경하지 않는다.
- `valueAccount(account, quote)`: 보유 평가액·평균 매입단가·실현/미실현 손익·현금 포함 총자산을 반환한다.

`order`는 `{id, symbol, side: 'buy'|'sell', quantity}`다. 수량은 양의 정수 주, 금액은 안전한 정수 원이다. `quote`는 `{symbol, price, tradable}`이며 가격은 양의 정수 원이다. 가격 선택·날짜 검증·월 진행은 다음 통합 단계에서 서버가 담당한다. 이 함수는 전달된 가격으로만 계산하며 미래 데이터를 선택하지 않는다.

## 정산과 반올림

- `costs = {feeBps: 0, sellTaxBps: 0}` 기본값은 테스트용 비용 0이다. 실제 제도의 요율을 뜻하지 않는다. 각 요율은 0~10000 정수 bps다(100bps=1%).
- 수수료는 매수·매도 각각 거래대금에, 세금은 매도 거래대금에 적용한다. Decimal로 각 비용을 별도로 계산하고 원 단위 HALF_UP 반올림한다.
- 매수 지출과 취득 원가 = 가격 × 수량 + 매수 수수료.
- 매도 순유입 = 가격 × 수량 - 매도 수수료 - 매도 세금. 비용이 거래대금을 초과하면 주문을 거부한다.
- 부분 매도의 제거 원가 = 기존 총원가 × 매도 수량 / 기존 보유 수량, 원 단위 HALF_UP. 전량 매도는 남은 원가 전액을 제거해 잔여 원가를 0으로 만든다.
- 실현손익 증가 = 순매도 대금 - 제거 원가. 미실현손익 = 평가액 - 남은 원가. 평균 매입단가는 남은 원가 / 수량을 소수점 6자리 문자열로 표시한다(0주이면 null). 평균 표시값으로 정산하지 않는다.
- 계좌 불변식: `cash + costBasis = initialCash + realizedPnl`. 같은 가격에서 매매 왕복하면 비용만큼 총자산이 감소한다.

## 오류·거부·중복

형식 오류(소수/0/음수 수량, 잘못된 방향·종목·ID·요율, 안전 정수 초과)는 코드가 있는 예외다. 계좌를 변경하지 않는다. 가격이 없거나 거래 불가, 종목 불일치, 현금/수량 부족, 매도 비용 초과는 `status: rejected` 기록이다. 부분 체결·자동 차입·자동 매도는 없다.

체결/거부 기록을 `account.executions`에 보존한다. 같은 ID와 동일 주문을 다시 호출하면 새 거래를 만들지 않고 기존 기록을 돌려준다. 이후 가격·비용이 달라져도 재체결하지 않는다. 같은 ID에 다른 주문 내용은 `ORDER_ID_CONFLICT` 예외다. 거부 주문을 수정하거나 다시 시도하려면 새 ID를 사용한다. 재시도 계좌 상태와 기록의 영속화·동시 요청 처리는 다음 서버 통합 범위다.

평가는 수량이 0이면 가격 없이 가능하다. 주식을 보유한 상태에서 유효 가격이 없으면 `PRICE_UNAVAILABLE` 예외로, 다른 종목 가격이면 `SYMBOL_MISMATCH` 예외로 실패한다. 거래 정지 여부는 체결만 제한하며 유효한 가격의 평가 자체를 막지 않는다. 직전 가격 사용·가격 지연 표시는 다음 데이터 계층에서 명시적으로 처리한다.

## 월별 현금 연결 확장

`applyCashFlow(account, delta)`는 비거래 현금 유입/유출을 추적한다. 계좌의 netCashFlow 기본값은 0이며 해당 필드가 없는 기존 계좌도 읽는다. 확장 불변식은 cash + costBasis = initialCash + netCashFlow + realizedPnl이다. 현금 이상 유출은 거부하며 원본을 변경하지 않는다. 월별 통합은 [v2 계약](monthly-investment-contract.md)을 따른다.
