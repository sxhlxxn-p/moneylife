# 저장 투자 사본 비교

`POST /paper-comparisons`: `{planIds:[UUID,UUID,(UUID)], throughMonth?:정수}`. 같은 게스트의 서로 다른 2~3개 사본을 비교한다. 입력 순서의 첫 사본이 기준이다. 같은 출발 financialPlanId·초기 조건·시작 월·가격 해시·엔진 버전만 허용한다.

비교 시점의 기본값은 선택 사본들이 모두 진행한 마지막 월의 최솟값이다. throughMonth는 0~공통 진행 월 안에서만 지정한다. 더 진행한 사본도 공통 월 이후의 행·목표 시점·부족 기록을 응답하지 않는다. 지원 데이터의 미래 가격을 열거나 사본을 자동 진행하지 않는다.

각 사본의 기존 Run을 검증하고 공통 월까지 잘라 현금·저축·주식 평가액·순자산·실현/평가 손익, 목표 최초 달성·부족 월 수·누적 미충족액을 요약한다. 목표 미달성은 공통 구간 안에서 아직 미달성이며 이후에도 미달성한다는 뜻이 아니다. 차이는 각 비교 사본에서 첫 사본을 뺀 값이다. 두 목표가 모두 달성됐을 때만 목표 월 차이를 반환한다.

계획·Run·주문·현재 화면 선택을 변경하거나 계산 엔진·외부 API·LLM을 호출하지 않는다. 원본 state·주문·전체 가격을 응답하지 않는다. 출발 조건/가격/엔진이 다른 비교는 409, 다른 게스트/없는 사본은 404, 중복/개수/형식은 422다. POST에는 기존 Origin 검사를 적용한다.

화면은 현재 사본을 기준으로 저장된 사본을 최대 2개 더 고른다. 진행 월이 다른 경우 공통 월까지만 비교한다는 안내를 표시한다. 미래 변경의 효과를 확인하려면 각 사본을 사용자가 해당 월까지 진행한 뒤 비교한다. 일반 현금·저축 Plan과 투자 PaperPlan을 섞어 비교하는 API는 아니다.
