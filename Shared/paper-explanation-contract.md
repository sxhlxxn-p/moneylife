# 투자 결과 해설

- `GET /paper-runs/{id}/explanation`: 저장된 본인 Run의 기본 해설. 외부 모델·시세·엔진을 호출하지 않는다.
- `POST /paper-runs/{id}/explanation`: `{useAI: true}`로 명시적으로 요청한 경우에만 선택형 AI 해설을 시도한다. 키·모델이 없거나 실패하면 기본 해설로 대체한다.

해설은 이미 진행한 월까지의 투자/비투자 결과를 비교한다. 순자산 차이, 목표 최초 달성, 현금·저축·주식 구성, 실현/평가 손익, 현금 부족, 체결/거부/대기 기록, 비용과 데이터 가정을 서버 문장으로 만든다. 목표 미달성은 아직 진행한 구간의 결과이며 120개월 전체의 미달성이나 미래 예측으로 설명하지 않는다.

LLM은 서버가 만든 사실 ID의 선택·읽기 순서만 결정한다. 문장·금액·원인·추천을 직접 생성하지 않는다. 비교·목표·가정은 반드시 포함하고 현금 부족 또는 가격 지연이 있으면 해당 사실도 필수다. 미등록 ID·중복·누락·임의 문장은 검증 실패이며 한 번 재요청 후 기본 해설로 대체한다. 수치와 방향 표현은 서버가 저장 결과에서 구성하므로 양수/음수·이익/비교 차이를 뒤바꾸지 않는다.

모델 입력은 해설용 사실 ID·제목·문장과 필수 ID 목록이다. 이름·계좌·인증정보·요청 원문·전체 가격·미래 가격·서버 입력 원본을 보내지 않는다. UI에서 외부 전송을 안내하고 별도 AI 버튼을 누른 경우에만 호출한다. 기본 해설은 LLM이 작성한 것으로 표시하지 않는다. AI 결과도 'AI가 읽기 순서를 정리한 해설'로 표시한다.

검증된 사실 ID 선택만 Run+프롬프트 버전+모델별로 저장한다. 다시 요청하면 같은 선택을 복원하고 최신 서버 문장을 연결한다. 다른 게스트는 캐시 여부와 관계없이 404다. 계획·주문·Run은 변경하지 않는다. 모델 응답·검증 실패·키 미설정의 대체 결과는 캐시하지 않는다.

자유 질의·종목 추천·주문 실행·자율 탐색·모델 학습은 이 단계에 포함하지 않는다. 외부 API를 미룬 상태에서는 기본 해설과 모의 응답 검증만으로 전체 흐름을 확인한다.
