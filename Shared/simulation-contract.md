# 서버 계산 결과 계약 v1

- `POST /simulations`: `{planId, requestId, months: 1~120(기본 120)}`. 서버에 저장된 본인 계획만 실행한다. 원시 계산 결과를 클라이언트에서 전달하지 않는다.
- 같은 게스트의 `requestId` 재전송은 기존 Run을 반환한다. 같은 ID에 다른 계획/기간을 지정하면 409다. 계산 실패는 Run으로 저장하지 않는다.
- `GET /simulations?planId={id}&limit=20`: 해당 계획의 본인 Run 목록.
- `GET /simulations/{id}`: 입력 스냅샷, 엔진 버전, 월별 결과와 요약. 재조회 시 재계산하지 않는다.
- 계획은 불변 스냅샷이므로 `planVersion=1`이다. 변경 계획은 별도 `planId`를 사용한다.
- `engineVersion=cash-savings-krw-v1`: API 금액을 정수 원으로 그대로 실행. Decimal 40자리로 유효 연 금리에서 월 금리를 구하고 월초 저축 이자를 원 단위 HALF_UP 반올림한다. 월말 이체는 다음 달부터 이자가 발생한다.
- 기간은 초기 상태 0개월과 계산 월 1~months를 포함한다. `goalMonth`는 `cash+saved-unpaid` 최초 달성 월, 기간 내 미달성은 null이다.
- 현금 부족액은 누적 미충족액이며 자동 대출/인출/상환을 하지 않는다. 기존 모형을 유지한다.
- 라이브 화면은 기존 만 원 실수 엔진의 미리보기다. 서버 결과는 원 단위 반올림 정책을 적용한 별도 결과 화면에서 표시한다. 이자 경계에서 미리보기와 작은 차이가 날 수 있다.
- 시세·투자·물가·대출 모델과 LLM은 이번 범위에 포함하지 않는다.
