# 재질문과 변경안 확인

## 대화 기준

금액이 없으면 금액을, 항목·연도·시점이 명시적으로 모호하면 필요한 정보를 질문한다. 시점이 아예 생략된 경우는 기존 계약대로 현재 진행 월의 다음 달부터 적용한다. 복합 요청은 각 항목의 금액을 확인하며 하나만 임의로 적용하지 않는다. 미지원 요청이 섞이면 부분 실행하지 않는다.

보충 답변은 원래 요청과 같은 계획에 연결한다. 서버는 이전 질문과 답변을 순서대로 전달한다. 질문 도중 사용자가 금액을 정정하면 그 대화 전체를 해석 대상으로 전달하되, 정정 내용을 실제 모델이 정확히 이해하는지는 API 연결 후 별도로 평가한다. 승인 전에는 재무 계획과 계산 결과를 만들지 않는다. 최대 세 번 보충할 수 있고 30분 만료·계획 소유권·진행 상태 변경을 검사한다.

Test/ai/dialogues-v1.json은 개발용 대화 네 가지다. 금액 누락, 항목/연도/금액 누락, 복합 요청, 재질문 중 금액 정정을 포함한다. 응답은 정해진 검증용 응답이며 실제 모델의 언어 이해 결과가 아니다. 기존 최종 평가 40건은 변경하지 않았다.

## 승인 화면

ready 응답의 previewDetails를 사용해 항목, 설정/증감 금액, 적용 시작·종료 시점, 변경 전후의 실제 월별 조건을 표시한다. 원래 계획에 미래 변경이 이미 있으면 같은 값이 유지되는 기간별로 나누어 보여준다. 복합 변경은 요청 순서대로 표시하며 같은 항목을 연속 변경하면 앞선 변경을 반영한 값을 다음 변경의 기준으로 사용한다.

표시 금액은 LLM이 작성하지 않는다. 서버의 build_candidate/effective에서 정한 원 단위 값으로 구성한다. 이 화면은 조건 변경 안내이며 계산 전 자산 예측을 모델 문장으로 대신하지 않는다. 기존 preview 문자열도 유지해 이전 응답을 사용하는 화면과 호환한다.

‘요청 수정’은 현재 계획을 변경하지 않고 입력란으로 돌아간다. 보충 답변을 통해 만든 변경안이면 원래 요청과 누적 보충 조건을 순서대로 함께 입력란에 넣는다. 수정을 전송하면 새 변경안을 요청하고 다시 승인해야 한다. 승인 직전 화면에서 부분 정정 문장만 보내 이미 확정 가능한 변경안을 자동 수정하는 전용 API는 추가하지 않았다.

## 모의투자 이벤트의 현재 범위

투자 화면의 ‘내 투자로 뉴스 체험’은 현재 투자 사본의 자산과 다음 달 생활 조건에서 시작하는 별도 게임이다. 금리 인상·유가 급등·경기 회복·고용 변화의 네 가지 가상 뉴스와 보유/절반 매도/전량 매도 선택을 제공한다. 결과 저장·복원·대응 경로 비교가 구현돼 있다.

실제 뉴스 수집이나 실제 뉴스에서 충격률을 추정하는 기능이 아니다. 원래 투자 사본의 가격·예약 주문·시간 진행에 충격을 합치는 기능도 아니다. 원본의 과거 주가를 보존하면서 별도 가정의 영향을 비교하는 범위를 유지한다.
