# 금융 계산 명세 초안

`Engine`은 UI, 네트워크, DB와 분리된 순수 계산 영역이다.

## 월 처리 순서

1. 시작 잔액의 이자·투자수익·부채 이자 반영
2. 순소득 입금
3. 생활비·의무 지출·부채 상환
4. 이벤트 지출
5. 가능한 현금 범위에서 저축·투자 이체
6. 월말 자산·목표·부족 기록

저축 이체는 자산 간 이동이므로 소비로 중복 차감하지 않는다. 현금 부족 시 자동 차입이나 자동 매각을 가정하지 않는다.

## 현재 구현 범위

현재 `Engine/src/index.js`는 현금·저축, 소득·생활비, 일회성 이벤트, 기간 소득 변화, 월말 저축 이체와 연 유효 수익률의 월복리를 만 원 단위로 계산한다. 투자·부채·물가·원 단위 계약은 후속 구현 대상이다.

회귀 기준 데이터는 `fixtures/expected-results`에 두며 동일 입력 재현성, 120개월 결과, 0% 수익률, 이체 시 총자산 보존, 현금 부족과 이벤트 1회 반영을 검증한다.
