# 금융 계산 명세 초안

`Engine`은 UI, 네트워크, DB와 분리된 순수 계산 영역이다.

## 월 처리 순서

1. 시작 잔액의 이자·투자수익·부채 이자 반영
2. 순소득 입금
3. 생활비·의무 지출·부채 상환
4. 이벤트 지출
5. 가능한 현금 범위에서 저축·투자 이체
6. 월말 자산·목표·부족 기록

저축 이체는 자산 간 이동이므로 소비로 중복 차감하지 않는다. 현금 부족 시 자동 차입이나 자동 매각을 가정하지 않는다.

## 현재 구현 범위

현재 `Engine/src/index.js`는 현금·저축, 소득·생활비, 일회성 이벤트, 기간 소득 변화, 월말 저축 이체와 연 유효 수익률의 월복리를 만 원 단위로 계산한다. 서버용 snapshot.cjs는 동일 처리 규칙에 정수 원과 Decimal 이자 반올림 정책을 적용한다. 투자·부채·물가는 후속 구현 대상이다.

회귀 기준 데이터는 `fixtures/expected-results`에 두며 동일 입력 재현성, 120개월 결과, 0% 수익률, 이체 시 총자산 보존, 현금 부족과 이벤트 1회 반영을 검증한다.

## 목표 기준 수정

목표는 `cash + saved - unpaid`가 목표 금액에 처음 도달하는 월이다. 비상금 300만 원은 목표에서 차감하지 않는다. 현금 부족 경고와 분리한다. `Engine.goalMonth()`와 화면의 목표 진행률에 같은 기준을 사용한다. 금리 0%, 현금 1,000만원, 소득 250만원, 생활비 160만원, 목표 2,000만원의 도달 월은 12개월이다. 첫 달 독립(이사비 300만원, 월 생활비 +30만원)은 22개월이다.

## 서버 결과 v1

서버는 월초 저축 잔액에 유효 연 금리의 월 금리를 적용한다. Decimal 40자리 계산 후 매월 원 단위 HALF_UP 반올림하고 월말 이체는 다음 달부터 이자를 받는다. 입력·엔진 버전·결과를 Run으로 저장하며, 조회할 때 다시 계산하지 않는다. 라이브 미리보기의 실수 계산과 서버의 원 단위 정책을 구분한다.

## 월별 투자 확장 v2

기존 월별 현금 처리에 투자 콜백을 연결했다. 생활비/이벤트를 낸 공유 현금으로 매도 → 매수 후 가능한 저축을 이체한다. 주식 평가액은 총자산에 한 번만 더한다. 저축 인출이나 주식 자동 매도, 부족액 자동 상환을 가정하지 않는다. 주문이 없으면 원 단위 v1과 월별 결과가 같다. 상세 가격·체결·지연·비교 규칙은 `Shared/monthly-investment-contract.md`를 따른다. 서버 API는 아직 v1이며 투자 함수는 별도 실행 명령으로 검증한다.
