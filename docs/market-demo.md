# 실제 주가 시연 자료 준비

시연 규격은 국내 한 종목(005930), 2024년 1~12월로 고정했다. 일봉을 수집해 각 월의 마지막 유효 원화 종가로 등록한다. 다음 달 가격은 진행 전 사용자에게 보내지 않으며 시작 시 가격 버전/해시를 고정한다. 배당·분할은 모델링하지 않는다.

추적되는 저장소에는 실제 가격을 넣지 않는다. 2026-11-23 개인 로컬 확인 요청으로 토스 API에서 삼성전자 2024년 1~12월 자료를 수집해 `.data/market/samsung-2024-toss-v1.json`에 등록했다. 월별 가격 12개, 누락 월 0개이며 Git 무시 대상이다. 다른 개발 환경에서는 동일 자료를 별도로 준비해야 한다. 가상 회귀 자료를 실제 주가라고 표시하지 않는다.

로컬 화면에서 **모의투자 → 새 투자 연습 → 사용할 가격 데이터 → 삼성전자 · 2024년 과거 시장 체험 → 예시 조건으로 체험**을 선택한다. 새로 연 화면에서는 새 투자 연습 버튼 없이 가격 선택부터 진행할 수 있다. 이미 시작한 가상 가격 사본은 그대로 유지되므로 실제 자료를 보려면 새 사본을 만든다. 월 0은 2024년 1월이고 11개월을 진행하면 2024년 12월이다.

## 설정

가상환경을 활성화하고 Server/.env에 TOSS_ACCESS_TOKEN을 넣거나 TOSS_CLIENT_ID와 TOSS_CLIENT_SECRET을 설정한다. Client와 Git에는 값을 넣지 않는다. 환경변수는 파일보다 우선한다.

토스 WTS에서 키와 호출 허용 IP를 설정해야 한다. Client Credentials 토큰은 수집 프로세스 시작 시 한 번 발급해 해당 일봉 수집에 재사용한다. 공식 인증 명세상 재발급은 기존 토큰을 무효화하므로 다른 실행과 공유하는 클라이언트의 수집을 동시에 실행하지 않는다. 이번 범위에 상시 서비스용 분산 토큰 관리나 자동 재시도 루프는 없다.

```bash
source .venv/bin/activate
npm run check:market
npm run prepare:market
```

두 명령의 기본 동작은 외부 요청이 없는 상태 확인이다. 키가 없으면 configured=false, 실제 등록 자료가 없으면 awaiting-collection을 표시한다.

실제 API 연결을 확인할 준비가 됐을 때만 실행한다.

```bash
npm run check:market -- --live
```

확인 후 프로젝트 표시 가능 범위를 검토하고 실제 자료를 등록한다.

```bash
npm run prepare:market -- --collect --project-usage-confirmed
```

이 명령은 새 자료를 등록하며 기존 버전을 덮어쓰지 않는다. 완료하면 실제 데이터 해시·누락 월을 확인하고, 모의투자 가격 목록에서 해당 자료를 선택한다. 이미 등록된 같은 시연 규격은 다시 수집하지 않는다. source와 기간을 바꿀 때는 새 버전 ID를 사용한다.

실제 연결 검증 전에는 인증/IP/데이터 이용 범위가 확인됐다고 기록하지 않는다. check --live는 연결을 확인할 뿐 가격 자료를 등록하지 않는다.

## 실거래 차단과 상태 API

토스 전용 HTTP 경계는 토큰 발급 POST와 일봉 조회 GET 두 경로만 허용한다. 다른 호스트·포트·경로·메서드와 계좌 헤더를 전송 전에 거부하고 리다이렉트를 따르지 않는다. 모의 매수·매도·취소·월 진행은 공용 엔진과 DB에서만 처리한다. 이 제한은 서버 코드의 정책이며 토스에서 발급한 키 자체의 권한이 축소되는 것은 아니다.

`GET /integrations/toss/status`는 토큰을 발급하거나 토스에 접속하지 않는다. 설정 여부, 인증 방식, 읽기 전용 정책, 등록된 공개 과거 자료 수와 마지막 검사 시각·성공 여부·고정 오류 코드만 반환한다. 마지막 검사가 없으면 `lastCheck=null`이다. 과거 검사 결과는 현재 연결 상태를 보장하지 않는다.

`Server/.env`에 토스 키와 별개의 무작위 운영자 키 `TOSS_OPERATOR_KEY`(32자 이상)를 설정한다. 요청 헤더는 `X-Moneylife-Operator-Key`다. 운영자 키 미설정은 503, 누락·불일치는 401이며 게스트 쿠키로 접근할 수 없다. Swagger의 Authorize에서도 입력할 수 있다. 키를 URL·프론트 코드에 넣지 않는다.

`check_market.py --live`의 결과는 기본 `.data/toss-status.json`에 원자적으로 저장된다. 상태 조회 API와 검사 스크립트가 다른 컨테이너에 있으면 동일한 영속 볼륨의 절대 경로를 `TOSS_STATUS_FILE` 환경변수로 지정한다. 이 변수는 프로세스 환경에서 읽는다. 기본 오프라인 검사는 파일을 갱신하지 않는다. 손상된 상태 파일은 503으로 처리하며 실패한 기록을 성공으로 표시하지 않는다.

Windows에서는 저장소 루트에서 다음처럼 실행할 수 있다. 별도 `PYTHONUTF8` 설정 없이 가격 카탈로그와 생애 이벤트 JSON을 UTF-8로 읽는다.

```powershell
& .\.venv\Scripts\python.exe Server/scripts/check_market.py --live
```

2026-11-23 로컬 실연동에서 Client Credentials 토큰 발급과 삼성전자 2024년 1월 일봉 22건 조회를 확인했다. 이어 1~12월 자료를 개인 로컬 화면 확인용으로 등록하고 실제 출처 표시·2주 모의 매수·다음 달 체결·새로고침 복원을 확인했다. 공개 서비스의 데이터 이용 권한 검증·계좌 조회·실주문 실행을 뜻하지 않는다.

같은 날 검증: 토스·시세 관련 회귀 64개, Node 73개, 구문·Ruff·포맷·`npm run check` 통과. 전체 서버 검사는 361개 통과·1개 실패다. 실패는 기존 `test_llm_setup.py`의 POSIX 파일 권한 0600 기대값이 Windows에서 0666으로 관측되는 항목이며 토스 연동 테스트는 모두 통과했다. 신규 상태 API는 키 없이 401, 운영자 키로 200과 저장된 성공 기록 반환을 확인했다.
