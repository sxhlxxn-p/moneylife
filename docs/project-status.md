# 현재 구현과 검증 범위

이 문서는 현재 상태의 기준이다. 실행은 [처음 시작하기](getting-started.md), 코드 경계는 [개발 구조](architecture.md)를 참고한다. 날짜별 진행 보고서는 당시 기록으로만 읽는다.

## 실제 구현

- Client: 정적 HTML·CSS·JavaScript. 재무 입력, 월별 진행, 생애 이벤트, 계획 비교·저장, 모의투자, 가상 뉴스 게임을 제공한다.
- Server: FastAPI·SQLAlchemy·Pydantic. 익명 세션의 소유권, 불변 계획·계산 결과, 재시도 요청 ID와 DB 마이그레이션을 관리한다.
- Engine: Node.js JavaScript 공용 계산. 정수 원과 월별 Decimal 이자 반올림을 사용한다. TypeScript 전환은 하지 않았다.
- DB: Docker 없는 로컬 실행은 SQLite, Compose와 격리 배포 검사는 PostgreSQL이다.
- LLM: 외부 모델 연결 어댑터와 구조화 추출·검증·재질문·사용자 승인·계산 비교·사실 문장 순서 선택 흐름이 있다. 계산은 엔진이 수행한다.
- 시장 데이터: 등록된 가격 자료와 가상 자료를 사용한다. 토스 실 API 인증·가격 수집은 완료된 기능으로 소개하지 않는다.

## 검증한 범위

Node 단위 검사, 임시 SQLite 기반 서버 검사, Chromium 브라우저 회귀 검사가 있다. GitHub 별도 작업은 PostgreSQL 재시도·동시 저장·소유권·재시작과 배포 이미지 빌드·HTTPS 쿠키·Origin 제한·백업 복원을 검사한다. 정확한 검사 수와 합격 여부는 각 변경의 CI 결과를 따른다.

LLM 통합 검사는 모의 응답과 실제 서버·DB·계산 엔진을 결합한다. 규칙 기준선 개발 60건은 46건 일치이고 실패 14건은 재질문으로 처리했다. 이것은 실제 LLM 성능이 아니다. 최종 40건의 모델 평가와 독립 정답 검수는 남아 있다.

## 남은 작업과 구분

- 실제 LLM·토스 API 연결과 품질·접근 권한 검증.
- 공개 서비스의 도메인·유효 인증서·운영 모니터링 설정. CI의 localhost HTTPS 검증과 구분한다.
- React·TypeScript 전환은 구현된 스택이 아니다. 기능 개발에 필수인 것으로 가정하지 않는다.
- 사용자 계정 로그인은 현재 익명 세션과 별도 범위다.
- 리포트 표시 정밀도, 전역 스크립트 의존성, 렌더·저장 분리, CSS·브라우저 테스트 구조는 프론트 후속 작업이다. 백엔드 구조 정리로 해결됐다고 간주하지 않는다.
