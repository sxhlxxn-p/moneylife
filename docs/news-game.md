# 가상 경제 뉴스 게임

메인 화면의 `뉴스 게임 체험`에서 API 키 없이 예시 포트폴리오로 시작한다. 저장 투자 연습의 `내 투자로 뉴스 체험`은 현재 Run의 현금·저축·보유 수량·확인된 가격과 조건 API의 소득·생활비를 출발점으로 사용한다.

## 진행

금리 인상(주가 −12%), 유가 급등(주가 −8%, 해당 생활비 +10%), 경기 회복(주가 +15%), 고용 둔화(주가 −5%, 해당 소득 −20%)가 정해진 순서로 발생한다. 직접 작성한 교육용 가정이며 실제 기사나 수익 예측이 아니다.

보유 유지·절반 매도·전량 매도 선택 후 손익과 현금 부족을 미리 확인하고 확정하면 1라운드가 진행된다. 절반 매도는 정수 주 내림이며 무보유 상태의 매도는 비활성화한다.

## 계산 범위

- 충격 전 확인 가격으로 매도한다는 게임 규칙이다. 실제 뉴스 발표 뒤 체결을 재현하거나 투자 능력을 평가하지 않는다.
- 1라운드=가상의 1개월. 매도 → 가정 가격 변동 → 월 소득·생활비 반영 순서다. 소득·생활비 충격은 해당 라운드에만 적용한다.
- 저축 잔액 고정, 저축 이체·이자·수수료·세금·대기 주문·생애 이벤트 제외. 기존 120개월 서버 계산과 구분되는 제한된 충격 실험이다.
- 현금 부족은 미충족 생활비로 누적한다. 저축·주식 자동 청산 없이 순자산=현금+저축+주식 평가액−미충족 생활비로 계산한다. 원 단위 HALF_UP 반올림을 적용한다.
- 주가 변화 손익과 전체 순자산 변동을 구분한다. 월 소득 때문에 순자산이 증가해도 주가 손실이 없었다고 설명하지 않는다.
- 진행한 라운드의 나의 대응과 계속 보유 경로를 비교한다. 과거 주가 원본이나 미공개 미래 가격은 사용·수정하지 않는다.

## 저장·통합

기존 Plan·PaperPlan·Run·주문·현재 선택은 변경하지 않는다. 브라우저에 가장 최근 게임의 Run ID와 선택 목록만 보관하고 복원 시 다시 계산한다. 예시 게임과 투자 사본의 게임은 분리한다. 서버 게임 저장·실제 기사 수집·뉴스 분류·충격 추정·원본 투자 경로와의 합성은 이번 범위에 없다.

계산은 `Client/src/news-scenario.js`, 화면은 `Client/src/news-game.js`에 분리했다. 계산 회귀 및 브라우저의 미리보기·복원·4라운드 종료·원본 보존을 검증한다.
