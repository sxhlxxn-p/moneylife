# Client

재무 입력, 시간 재생, 생애 이벤트, 자산 차트와 계획 비교 화면의 소유 경로다.

현재는 프레임워크 없는 동작 클라이언트다. 이번 구조 정리에서는 React·TypeScript로 전환하지 않는다.

- `index.html`: 화면 구조와 SVG 월드
- `src/app.js`: 화면 상태, 이벤트와 로컬 저장
- `src/styles.css`: 디자인 토큰과 반응형 스타일
- 계산은 `../Engine`의 순수 함수를 사용한다.
- 서버 연결 전 공통 데이터는 `../fixtures`에서 관리한다.
- API 연동 시 요청·응답 형식은 `../Shared`의 공통 계약을 사용한다.
- 이전 정적 초안 원본은 `../prototype`에 보관한다.

## 팀 작업 기준

- 프론트엔드 담당자는 화면 구조, 반응형 스타일, 접근성, 브라우저 상태와 API 호출을 소유한다.
- 금융 수식을 `app.js`에 추가하지 않고 `Engine` 또는 Server API를 통해 사용한다.
- 인증정보와 외부 API 키를 브라우저 코드에 넣지 않는다.
- 정적 자산이 실제로 추가되기 전에는 빈 `public`이나 `assets` 폴더를 만들지 않는다.
- 화면 계약 변경 시 `../docs/FRONTEND_HANDOFF.md`와 `../docs/api-contract.md`를 함께 갱신한다.
