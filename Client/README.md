# Client

재무 입력, 시간 재생, 생애 이벤트, 자산 차트와 계획 비교 화면의 소유 경로다.

현재는 프레임워크 없는 동작 클라이언트다. React·TypeScript 전환은 별도 합의 후 진행한다.

- `index.html`: 화면 구조와 SVG 월드
- `src/app.js`: 화면 상태, 이벤트와 로컬 저장
- `src/styles.css`: 디자인 토큰과 반응형 스타일
- 계산은 `../Engine`의 순수 함수를 사용한다.
- 서버 연결 전 공통 데이터는 `../fixtures`에서 관리한다.
- API 연동 시 요청·응답 형식은 `../Shared`의 공통 계약을 사용한다.
- 이전 정적 초안 원본은 `../prototype`에 보관한다.

## 팀 작업 기준

- 프론트엔드 담당자는 화면 구조, 반응형 스타일, 접근성, 브라우저 상태와 API 호출을 소유한다.
- 금융 수식을 `app.js`에 추가하지 않고 `Engine` 또는 Server API를 통해 사용한다.
- 인증정보와 외부 API 키를 브라우저 코드에 넣지 않는다.
- 정적 자산이 실제로 추가되기 전에는 빈 `public`이나 `assets` 폴더를 만들지 않는다.
- 화면 계약 변경 시 `../docs/FRONTEND_HANDOFF.md`와 `../docs/api-contract.md`를 함께 갱신한다.


## 투자 연습실

메인 화면에서 **모의투자 열기**를 누른다. 서버가 실행 중이어야 한다.

- **현재 여정의 사본으로 시작**: 입력한 현금·소득·지출·저축 조건과 현재 진행 월을 별도 재무 계획에 보관한다. 본편의 시간·서버 계획 ID는 바꾸지 않는다.
- **예시 조건으로 체험**: 현금 100만 원, 월 소득 20만 원·생활비 10만 원·저축 5만 원, 목표 125만 원으로 시작한다.
- 주식 수량을 입력해 매수·매도를 예약하고 **다음 달로 +1개월**을 누르면 서버가 체결 여부를 판단한다. 현금 부족 주문은 거부 기록으로 남는다.
- 보유 주식, 평가·실현 손익, 비투자 경로와의 순자산·목표 달성·현금 부족 차이를 현재 시점까지 표시한다.
- **저장한 투자 연습**에서 이전 시점을 선택해 다른 선택으로 분기할 수 있다. 새로고침 후 열면 마지막으로 선택한 투자 계획을 복원한다.

현재 가상 가격은 0~4개월만 지원한다. 본편이 4개월을 지났다면 예시 조건으로 시작한다. 실제 주가·실제 주문은 연결하지 않았으며 수수료·세율 0의 검증용 조건이다. 시세 원본이나 미래 가격을 브라우저에 저장하지 않는다.

응답 유실 시 같은 요청 번호를 이 기기에 보관하고 다른 주문·월 진행을 잠근다. **같은 요청 다시 확인**으로 결과를 확인하며 새로고침 뒤에도 동일 번호를 사용한다. 브라우저 저장 공간을 사용할 수 없으면 주문을 보내지 않는다. 서버 쿠키가 만료되거나 삭제되면 이전 게스트 데이터는 복원할 수 없다.

```bash
# 프로젝트 루트, 첫 번째 터미널: Python 의존성이 설치된 가상환경 사용
.venv/bin/python Server/run_local.py
# 두 번째 터미널
npm run dev
```

`src/paper-client.js`가 투자 화면과 API 호출을 담당한다. 수식은 화면에 구현하지 않고 서버의 저장 결과를 사용한다. API는 [모의투자 계약](../Shared/paper-api-contract.md)을 따른다.

### 등록된 과거 주가 선택

서버에 프로젝트 표시용 과거 가격이 등록되어 있으면 시작 화면의 **사용할 가격 데이터**에서 선택한다. 가상 가격과 실제 과거 주가를 구분해 표시하고 출처와 재생 기간을 제공한다. 현재 재무 조건의 경과 월 0을 선택한 주가의 첫 달에 대응시킨다. 가격과 체결 날짜는 과거 주가 기준 월을 표시하며 본편의 날짜·시간은 유지한다. 사용자별 종목 검색·실시간 호가·즉시 시세 갱신은 아직 제공하지 않는다.

### 주문 전 확인

수량 입력 후 매수/매도 예약을 누르면 확인 화면이 열린다. 현재까지 확인된 가격 기준의 거래대금·수수료·세금, 현재 현금, 다음 달 소득·지출과 기존 예약·월말 저축을 반영한 참고 현금·저축을 보여준다. **예약 확정**을 눌러야 주문이 생성된다. 수량 수정·닫기·Escape·새로고침은 예약하지 않는다.

이 화면은 실제 다음 달 가격을 미리 계산하지 않는다. 현재 가격이 유지되고 거래 가능하다는 가정이며, 가격이 없는 경우 금액을 표시하지 않는다. 다음 달 실제 시세와 현금으로 체결 여부를 다시 판단한다. 확인 중 보던 수량은 고정되며 다른 수량은 취소 후 다시 확인한다. [주문 확인 계약](../Shared/order-preview-contract.md)을 따른다.

### 투자 결과 해설

비교 화면 아래 **기본 해설 보기**는 저장된 현재 Run의 순자산 차이·자산 구성·실현/평가 손익·목표·현금 부족·주문 기록·가정을 서버 문장으로 설명한다. 외부 API를 호출하지 않으며, 다음 달로 진행한 뒤에는 새 결과에 대해 다시 조회한다.

**AI로 핵심 지표 정리**를 누른 경우에만 해설용 금융 지표 문장을 외부 모델에 전송한다. LLM은 검증된 사실 ID의 선택과 순서를 정하고 문장·수치·추천을 생성하지 않는다. 이름·계좌·가격 원본은 전송하지 않는다. 키 미설정·호출/검증 실패 시 기본 해설을 표시한다. 기본 해설과 AI가 선택한 해설의 출처를 구분해 표시한다. API 연결을 미룬 상태에서도 기본 해설은 사용할 수 있다.

### 대기 주문 취소

체결 대기 목록의 **주문 취소 → 취소 확정**으로 선택한 주문을 제외한 새 사본을 저장한다. 체결 전 매수는 현금을 차감하지 않았으므로 취소로 현금이 증가하지 않는다. 매도 예약을 취소하면 해당 수량만큼 다시 매도할 수 있다. 체결·거부된 기록에는 취소 버튼을 표시하지 않는다.

이전 시점과 다른 사본은 유지된다. 저장 목록의 **주문 취소** 표시로 취소 사본을 찾을 수 있다. 확인 화면에서 주문 유지·닫기를 누르면 취소 명령을 보내지 않는다. 응답 유실 시 다른 명령을 잠그고 새로고침 후에도 같은 취소 요청 번호로 다시 확인한다.

### 투자 중 생활 조건 변경

투자 연습실의 **생활 조건 변경**에서 다음 달 예정 소득·생활비·저축 이체액을 확인한다. 금액은 정수 원으로 입력하고 **변경 내용 확인 → 다음 달부터 적용**을 눌러 새 사본을 저장한다. 취소·닫기는 저장하지 않는다.

바꾼 항목만 다음 달부터 가격 지원 마지막 달까지 입력 금액으로 설정한다. 그 항목에 예정된 미래 변동도 지정 금액에 맞춰 조정한다. 다른 항목과 일회성 지출·금리·보유 주식·대기 주문은 유지한다. 지금까지의 계산 결과는 바뀌지 않으며 새 조건의 자산 변화는 월을 진행한 뒤 확인한다. 마지막 달에는 변경 버튼을 비활성화한다. 원본은 저장 목록에 남고 변경 사본은 **생활 조건 변경**으로 표시한다.

### 저장 투자 사본 비교

**투자 사본 비교**에서 현재 사본을 기준으로 최대 두 사본을 더 선택한다. 같은 출발 조건과 가격 버전만 비교하며, 모두 진행한 공통 시점까지의 순자산·구성·목표·현금 부족과 차이를 보여준다. 더 진행한 사본의 이후 목표 기록을 공통 구간에 섞지 않는다. 비교 때문에 사본을 자동 진행하거나 현재 선택·주문을 바꾸지 않는다. 생활 조건의 효과는 각 사본을 적용 월까지 직접 진행한 뒤 비교한다.

## 가상 경제 뉴스 게임

메인 `뉴스 게임 체험`은 서버 없이 예시 포트폴리오로 실행한다. 투자 사본의 `내 투자로 뉴스 체험`은 현재 자산에서 시작한다. 4개 가상 뉴스·3가지 대응·손익 미리보기·보유 경로 비교·브라우저 복원을 제공한다. 기존 투자 사본과 분리된 충격 실험이며 [게임 규칙](../docs/news-game.md)을 따른다.

투자 사본 뉴스 게임에는 서버 저장/목록/이어하기를 제공한다. 브라우저 선택만 서버에 보내며 서버 재계산 결과를 확인한다. 재시도 요청 ID를 브라우저에 유지한다. 예시 게임은 로컬 체험으로 유지한다.
