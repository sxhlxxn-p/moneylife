# Client

재무 입력, 시간 재생, 생애 이벤트, 자산 차트와 계획 비교 화면의 소유 경로다.

현재는 프레임워크 없는 동작 클라이언트다. React·TypeScript 전환은 별도 합의 후 진행한다.

- `index.html`: 화면 구조와 SVG 월드
- `src/app.js`: 화면 상태, 이벤트와 로컬 저장
- `src/styles.css`: 디자인 토큰과 반응형 스타일
- 계산은 `../Engine`의 순수 함수를 사용한다.
- 서버 연결 전 공통 데이터는 `../fixtures`에서 관리한다.
- API 연동 시 요청·응답 형식은 `../Shared`의 공통 계약을 사용한다.
- 이전 정적 초안 원본은 `../prototype`에 보관한다.

## 팀 작업 기준

- 프론트엔드 담당자는 화면 구조, 반응형 스타일, 접근성, 브라우저 상태와 API 호출을 소유한다.
- 금융 수식을 `app.js`에 추가하지 않고 `Engine` 또는 Server API를 통해 사용한다.
- 인증정보와 외부 API 키를 브라우저 코드에 넣지 않는다.
- 정적 자산이 실제로 추가되기 전에는 빈 `public`이나 `assets` 폴더를 만들지 않는다.
- 화면 계약 변경 시 `../docs/FRONTEND_HANDOFF.md`와 `../docs/api-contract.md`를 함께 갱신한다.


## 투자 연습실

메인 화면에서 **모의투자 열기**를 누른다. 서버가 실행 중이어야 한다.

- **현재 여정의 사본으로 시작**: 입력한 현금·소득·지출·저축 조건과 현재 진행 월을 별도 재무 계획에 보관한다. 본편의 시간·서버 계획 ID는 바꾸지 않는다.
- **예시 조건으로 체험**: 현금 100만 원, 월 소득 20만 원·생활비 10만 원·저축 5만 원, 목표 125만 원으로 시작한다.
- 주식 수량을 입력해 매수·매도를 예약하고 **다음 달로 +1개월**을 누르면 서버가 체결 여부를 판단한다. 현금 부족 주문은 거부 기록으로 남는다.
- 보유 주식, 평가·실현 손익, 비투자 경로와의 순자산·목표 달성·현금 부족 차이를 현재 시점까지 표시한다.
- **저장한 투자 연습**에서 이전 시점을 선택해 다른 선택으로 분기할 수 있다. 새로고침 후 열면 마지막으로 선택한 투자 계획을 복원한다.

현재 가상 가격은 0~4개월만 지원한다. 본편이 4개월을 지났다면 예시 조건으로 시작한다. 실제 주가·실제 주문은 연결하지 않았으며 수수료·세율 0의 검증용 조건이다. 시세 원본이나 미래 가격을 브라우저에 저장하지 않는다.

응답 유실 시 같은 요청 번호를 이 기기에 보관하고 다른 주문·월 진행을 잠근다. **같은 요청 다시 확인**으로 결과를 확인하며 새로고침 뒤에도 동일 번호를 사용한다. 브라우저 저장 공간을 사용할 수 없으면 주문을 보내지 않는다. 서버 쿠키가 만료되거나 삭제되면 이전 게스트 데이터는 복원할 수 없다.

```bash
# 프로젝트 루트, 첫 번째 터미널: Python 의존성이 설치된 가상환경 사용
.venv/bin/python Server/run_local.py
# 두 번째 터미널
npm run dev
```

`src/paper-client.js`가 투자 화면과 API 호출을 담당한다. 수식은 화면에 구현하지 않고 서버의 저장 결과를 사용한다. API는 [모의투자 계약](../Shared/paper-api-contract.md)을 따른다.
